プライバシーポリシー

1. YouTube API サービスの利用

当サイトは YouTube API サービス（YouTube 埋め込みプレーヤー / IFrame Player API）を利用して動画を表示しています。動画の再生にあたり、YouTube（Google）が Cookie 等を使って情報を収集する場合があります。利用者は YouTube 利用規約 に同意したものとみなされます。Google による情報の取り扱いは Google プライバシーポリシー をご確認ください。

2. Cookie・ローカルストレージ

当サイト自体は Cookie を発行しません。表示言語・最後に選んだテーマ・ホーム画面追加の案内を閉じたかどうかを、お使いの端末のブラウザ（localStorage）にのみ保存します。これらはサーバーに送信されず、ブラウザの設定から削除できます。オフライン表示のため Service Worker でページの一部をキャッシュします（YouTube の映像はキャッシュしません）。

3. 外部サービス

天気表示に Open-Meteo、地図表示に Leaflet / Esri World Imagery、文字表示に Google Fonts を利用しており、表示の際にこれらのサーバーへ通信が発生します。
